## About

**gitsnap** is a git snapshot & rollback tool.

### Key Features

- Instant git snapshots
- Quick rollback to any snapshot
- Single file
- Zero dependencies
- List/delete snapshots

---

## Tech Stack

- Node.js
- child_process
- fs

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `save` | Create snapshot |
| `list` | List snapshots |
| `rollback` | Restore snapshot |
| `delete` | Remove snapshot |
